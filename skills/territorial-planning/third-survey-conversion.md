## 前置知识

转换规则和完整映射表请查询知识库（RAG）中的以下文档：
- `land-classification-lookup.md` — 89 个三调代码与 140 个用地用海代码的完整映射表

- `land-sea-classification.md` — 2023 用地用海分类标准全文

**Agent 操作**：先查知识库中的 `land-classification-lookup.md` 和 `land-sea-classification.md`：
- `convert_sd_to_yh <三调代码>` — 查询单个代码的映射

## 执行流程

### 步骤 1：确认数据版本和转换方向

**目标**：确定源数据用的什么分类标准，要转成什么。

**判断逻辑**：
- 如果有 `DLBM` 字段 → 源数据是三调分类（GB/T 21010-2017）
- 如果有 `YDYH` 或 `GHDLBM` 字段 → 可能已经是新分类
- 如果有 `JQDLBM` 字段 → 是基期年数据（含历史分类）

**转换方向**：
| 源 | 目标 | 常用场景 |
|----|------|---------|
| 三调(GB/T 21010) | 用地用海(2023) | 规划编制基期转换 |
| 三调 | 三大类(农用地/建设用地/未利用地) | 面积核算 |
| 用地用海 | 三调 | 向上汇报/对接 |

### 步骤 2：执行代码转换

**目标**：将三调代码转为用地用海代码。

**主要变化提示**（详细映射请查 RAG）：
- 02 种植园用地 → 改称"园地"
- 05 商业服务业用地 → 新增 05H1 等子类
- 07 住宅用地 → 改称"居住用地"，0702 宅基地拆出 0703
- 10 交通运输用地 → 新增 1002 轨道交通
- 新增一级类 12-17（农业设施建设用地、村庄建设用地等）和 HH 混合用地
- 三调的 00 湿地大类 → 用地用海保留 00 但子类结构不同

**Agent 操作**：
1. 对不确定的代码，逐条查 `land-classification-lookup.md`
2. 对简单的 1:1 映射，直接使用 `management_CalculateField` 批量填入
3. 对 1:N 映射（需要人工判断的），参考下一步

### 步骤 3：处理特殊分类（一对多映射）

**目标**：处理三调→用地用海中需要结合上下文判断的分类。

常见的一对多情况（详细列表请查 RAG 中的 `land-classification-lookup.md`）：
- 05 商业服务业用地 → 05 / 05H1 / 0508（判断依据：地块名称含"物流/仓储"→0508）
- 08 公服用地 → 08 / 08H1 / 08H2 / 0809 / 0810（判断依据：名称含"机关"→08H1，"学校"→08H2，"公园"→0810）
- 11 水域 → 11 / 1104A / 1107A（判断依据：含"养殖"→1104A，"干渠"→1107A）

**处理方式**：
1. 列出涉及一对多转换的图斑清单
2. 根据图斑的其他属性（名称、位置、用地性质字段）尝试自动判断
3. 无法自动判断的标记为"需人工确认"

### 步骤 4：添加新增分类

三调没有但用地用海新增的一级类：12 农业设施建设用地、13 村庄建设用地、14 区域基础设施用地、15 其他建设用地、16 陆地水域、17 渔业用海、HH 混合用地。

如果项目中需要识别这些新分类的地块（比如通过规划用途字段判断），逐一处理。

### 步骤 5：验证转换结果

**目标**：确保转换后的代码都在用地用海有效范围内。

**Agent 操作**：
1. 用 `agent_describe_layer` 查看目标字段的唯一值分布
2. 用 `land-classification-lookup.md` 验证每个值在用地用海字典中
3. 对于不在字典中的值，标记为"无效代码"
4. 用 `analysis_Statistics` 按新分类统计面积，检查合理性

## 输出确认清单

## 实际踩坑记录

### 坑1：K 后缀可调整地类
三调的 `0201K`（可调整果园）→ 用地用海中如何处理？
- 如果去掉 K → `0201` 园地
- 实际上 `0201K` 表示该地块当前是果园但可以调整为其他用途
**处理方式**：保留 K 标识，在备注字段中标注"可调整"

### 坑2：三调湿地（00）
三调中 `00` 是湿地大类，包含 `0303` 红树林等。用地用海中 `00` 是湿地一级类，但子类结构不同。
**处理方式**：需要逐子类核对映射关系，不能简单用一级类映射。具体映射查 RAG 中的 `land-sea-classification.md`。

### 坑3：不同年份三调数据的差异
2018年基准的三调数据与2023年开展的年度更新数据，部分图斑的分类可能已有变化。
**处理方式**：确认用户使用的数据版本，必要时使用 `JQDLBM` 和 `GHDLBM` 区分。
