# 村庄规划数据入库流程

## 触发条件
用户提到以下任一关键词：
- "村庄规划"、"村规"、"村庄"
- "入库"、"数据入库"、"建库"
- "数据库规范"、"村级数据库"
- "村庄规划编制"、"乡村振兴"
- "福建村庄规划"、"省级村庄规划"

## 执行流程

### 步骤 1：准备标准空库

**目标**：创建符合规范的村庄规划地理数据库结构。

**Agent 操作**：
1. 创建 GDB：在工作空间创建 `agent_workspace/village_plan.gdb`
2. 创建标准要素类（共 10+ 个必需图层）：

| 图层名 | 几何类型 | 说明 |
|--------|---------|------|
| YJBNT | 面 | 永久基本农田 |
| STHX | 面 | 生态红线 |
| CZKF | 面 | 城镇开发边界 |
| JSD | 面 | 建设用地 |
| NT | 面 | 农用地 |
| QT | 面 | 其他用地 |
| DL | 线 | 道路 |
| HL | 线 | 河流 |
| JCSJ | 点 | 基础设施 |
| GGFW | 点 | 公共服务设施 |

**Fields 标准字段**：
- YSDM（要素代码，TEXT 10）
- BSM（标识码，TEXT 18）
- DLBM（地类编码，TEXT 10）
- JSMJ（计算面积，DOUBLE）
- TBBH（图斑编号，TEXT 20）
- QSXZ（权属性质，TEXT 20）

**Agent 操作**：
```bash
# 对每个图层执行：
management.CreateFeatureclass agent_workspace/village_plan.gdb <图层名> <几何类型> <坐标系>
# 然后逐个添加标准字段
management.AddField <图层名> YSDM TEXT
management.AddField <图层名> BSM TEXT
# ... 依此类推
```

### 步骤 2：导入原始数据

**目标**：将各类来源数据导入到标准库中。

常见数据来源：
| 格式 | 来源 | 处理方式 |
|------|------|---------|
| .shp | 测绘院/自规局 | 直接导入 GDB |
| .dwg | CAD测绘 | CAD至地理数据库 |
| .xlsx | 属性数据 | Excel转表 |
| .kml | 国土调查云 | KML转要素类 |

**Agent 操作**：
1. 识别数据格式：列出项目目录下的所有 GIS 相关文件
2. 对每种格式执行对应导入操作
3. 导入后检查坐标系是否与标准库一致

### 步骤 3：字段映射与标准化

**目标**：将导入数据的字段映射到标准字段。

**Agent 操作**：
1. 列出每个图层的字段列表
2. 识别与标准字段对应的源字段（通过名称模糊匹配）
3. 对于不匹配的字段，询问用户映射关系
4. 执行字段计算：`management.CalculateField <目标图层> <标准字段> '!<源字段>!' PYTHON3`

### 步骤 4：数据质量检查

**目标**：确保入库数据满足规范要求。

**Agent 操作**：
1. 完整性：`agent_describe_layer` + `management_SelectLayerByAttribute` 检查所有图层的必填字段
2. 准确性：`agent_get_map_info` + `management_Project` 检查坐标系和面积字段
3. 一致性：`analysis_Intersect` / `analysis_Erase` 检查图层间逻辑
4. 拓扑：`analysis_Intersect` 检查面重叠/线悬挂

### 步骤 5：生成入库成果

**目标**：生成入库报告和成果包。

**Agent 操作**：
1. 生成质量评估报告：根据上述检查结果输出到 `agent_workspace/quality_report.md`
2. 导出标准 GDB：确认所有图层都在 `village_plan.gdb` 中
3. 生成图层清单：列出所有要素类、要素数量、字段数

## 输出确认清单
- [ ] 所有必需图层都已创建或导入
- [ ] 每个图层都有 YSDM、BSM 等标准字段
- [ ] 坐标系统一为 CGCS2000 对应带号
- [ ] 必填字段空值率 < 1%
- [ ] 所有面图层无非法重叠
- [ ] 面积字段已计算（椭球面积，公顷）
- [ ] 数据质量报告已生成

## 实际踩坑记录

### 坑1：CAD 数据的高程信息
从 CAD 导入的 DWG 数据可能带有 Z 值（高程），导致平面分析异常。
**处理方式**：导入后用 `management.AddGeometryAttributes` 或 Python 清除 Z 值。

### 坑2：多源数据坐标系不一致
不同来源的数据可能使用不同坐标系（CGCS2000 3度带、6度带、WGS84）。
**处理方式**：统一用 `management.Project` 转换（不是 DefineProjection！）。

### 坑3：村庄规划的用地分类
村庄规划中的建设用地分类（如宅基地、公共设施用地等）可能使用地方标准。
**处理方式**：确认用户使用的分类标准，必要时查 `land-classification-lookup.md` 找对应关系。

## 福建村庄规划特别要求

福建省村庄规划有省级规范，需使用对应的村庄规划专用工具模块。

**福建省特殊要求**：
- 数据库命名需含行政区划代码
- 需要额外的图层：村庄建设边界、农村居民点、历史文化保护线
- 需要生成"一村一图"布局
- 产出包含 PPT 汇报材料

**Agent 操作提示**：
如果检测到项目在福建省，且包含 `FJ` 前缀的图层名，
应提示用户是否需要福建省专用入库流程。
