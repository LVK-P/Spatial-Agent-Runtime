# Skills 目录 —— Agent 的"专业知识"

## 概念

每个 `.md` 文件 = Agent 可以加载的一个专业技能模块。
Skill 用 Markdown 编写，AI 可以直接理解和执行。

## 如何编写一个 Skill

### 标准模板

```markdown
# Skill 名称

## 触发条件
（用户说什么关键词时会触发这个 Skill）

## 执行流程
（分步骤描述，每步包含：目标 → 检查项 → 操作 → 常见坑）

## 输出确认清单
（做完后要确认的检查项，用 checkbox 格式）

## 实际经验记录
（你自己在工作中遇到的具体案例、坐标系对照等）
```

### 编写原则

1. **写给新人看的口吻**：假设读这份 Skill 的是一个刚入职 0 经验的规划师
2. **包含踩坑经验**：不仅仅是操作步骤，还有"这里容易出错，因为..."
3. **具体的参数值**：不要写"转换坐标系"，写"用投影工具，源 4527 → 目标 4543"
4. **可验证的输出**：每个 Skill 结尾都有"确认清单"——做完后怎么验证对不对

## 版本迭代

- 新增知识 → 新建 `.md` 文件
- 修改知识 → 直接编辑文件
- 用 Git 追踪所有改动
