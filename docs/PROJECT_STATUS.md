# 项目状态

## 当前状态

- Runtime 代际：v3
- 宿主环境：Windows 上的 ArcGIS Pro 3.4
- 目标框架：.NET 8
- 工具接入：内置核心工具 + 可选的本地 GP 接口 manifest
- 自动化测试：源验证环境中 521 项全部通过
- Add-In：已使用 Visual Studio MSBuild 验证 Release 构建、打包与注册

## 已验证能力

- 多轮工具调用与确定性续行；
- 目标、对象、能力与证明闭包；
- 只读探查与部分目标推进；
- 四级风险处理、备份与审批；
- 基于真实 ArcGIS 状态的后置条件验证；
- 参数级长度/面积证明；
- 精确批次审批与稳定 Action 去重；
- Transcript、Ledger 与 Audit 关联；
- Checkpoint、项目记忆与过期会话恢复；
- 本地知识与基于 Skills 的工具提升；
- 只读 MCP 访问。

## 当前边界

- 只有 ArcGIS Pro 宿主适配器具备生产级现场证据。
- 完整构建与测试需要获得许可的 ArcGIS Pro 程序集。
- 工具可用性取决于本地安装的 ArcGIS 扩展模块。
- 当前 LLM 集成兼容 DeepSeek 协议；新增供应商应实现 `ILLMProvider`，而不是侵入 Runtime。
- 公开发行不携带厂商生成目录；本地动态工具默认采用 `Destructive` 级别，降级前必须由使用者审查。
- 端到端性能仍在很大程度上受模型延迟与上下文规模影响。
