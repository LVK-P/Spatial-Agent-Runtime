## 常见用户查询 → 转换逻辑

| 用户问 | 需要执行的转换 | Tool调用 |
|--------|--------------|---------|
| 把耕地全转成园地 | 01→02 + GetChildren("01) + GetChildren("02) | 先查映射表，再展开 01 和 02 的子类 |
| 计算林地的总面积和占比 | GetDescendants("03) → ["0301,"0302,"0303,"0304"] → Statistics SUM | 先展开 03 的子类，再做统计汇总 |
| 三调的0305在新标准是什么 | ConvertSdToYh("0305) → "0303" + "灌木林地" | 先查 0305 的映射结果，再确认新标准含义 |
| 城镇住宅用地代码 | FindByName("城镇住宅用地) → "0701" | 直接查名称对应代码 |
| 060202是什么地类 | LookupCode("060202) → "畜禽养殖设施建设用地" level=3 | 直接查代码对应地类 |
| 这个斑块是农用地还是建设用地 | GetSdCategory(code) | 先判断代码所属大类，再决定是否需要转换 |
| 列出所有一级类 | GetLevel1Codes() → 24个一级类列表 | 直接列出一级类 |
| 旧数据（三调）转新标准 | ConvertSdToYh() 逐条 | 逐条查映射后再批量转换 |
| 用地分类面积汇总 | GetLevel1Codes() → 对每个一级类展开子类 → Statistics SUM | 多步调用 |
| 永久基本农田的图层属性表名 | 永久基本农田 → 图层表 YJJBNT（来自database-spec.md） | 跨文档查询，需同时检索 database-spec |

## 常用面积计算GP工具

计算地类面积时：
- 字段名用 `!shape.geodesicArea@squarekilometers!`（测地线面积）或 `!shape.area!`（平面面积）
- 汇总用 `analysis.Statistics`，案例字段加 `SUM`
- 占比用 `management.CalculateField`：`!SUM_Area! / <总面积> * 100`
- 用地类型字段可能是 `DLBM`/`DLMC`（三调）或 `YDLX`（用地用海）
- 数据库规范要求坐标系统 CGCS2000，高程基准 1985
