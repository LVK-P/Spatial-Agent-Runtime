# 国土空间规划 — 用地分类标准

## 三调分类体系（GB/T 21010）

第三次全国国土调查（三调）将土地分为以下一级类：

| 编码 | 名称 | 常见GI S操作 |
|------|------|-------------|
| 01 | 耕地 | 面积统计、坡度分级 |
| 02 | 园地 | 面积统计 |
| 03 | 林地 | 面积统计、森林覆盖率 |
| 04 | 草地 | 面积统计 |
| 05 | 商服用地 | 面积统计 |
| 06 | 工矿仓储用地 | 面积统计、集约利用评价 |
| 07 | 住宅用地 | 面积统计、人均指标 |
| 08 | 公共管理与公共服务用地 | 面积统计、人均指标 |
| 09 | 特殊用地 | 面积统计 |
| 10 | 交通运输用地 | 面积统计、路网密度 |
| 11 | 水域及水利设施用地 | 面积统计 |
| 12 | 其他土地 | 面积统计 |

## 常用面积单位换算

- 1 平方公里 = 100 公顷 = 1,000,000 平方米
- 1 公顷 = 10,000 平方米
- 1 亩 ≈ 666.67 平方米
- 默认数据单位为平方米

## 计算面积时的 ArcGIS 表达式

使用 CGCS2000 地理坐标系时：
- 测地线面积：`!shape.geodesicArea@squarekilometers!`（推荐）
- 平面面积：`!shape.area!` (仅在投影坐标系下准确)
