# 从 ArcGIS Pro 地图坐标定位项目位置的方法

## 核心原则

**永远不要直接用地图像素/投影坐标当经纬度用。**

## 正确的定位流程

### 1. 先读坐标系 WKID

```
WKID=4326  → WGS84 地理坐标系（经纬度，单位：度）
WKID=4490  → CGCS2000 地理坐标系（经纬度，单位：度）
WKID=3857  → Web Mercator 投影坐标系（米，非经纬度！）
WKID=4523~4549 → CGCS2000 3度带投影（米）
```

### 2. 投影坐标系必须转换

如果 WKID 是投影坐标系（如 3857 Web Mercator）：
- 地图中心坐标（X, Y）是**米**，不能直接用作经纬度
- 必须通过 Pro SDK `GeometryEngine.Instance.Project()` 转换到 WGS84(4326) 或 CGCS2000(4490)
- 转换后的 X=经度(°), Y=纬度(°)

## 常见错误

1. **把 Web Mercator 的米坐标当成经纬度**——X=12,294,187 不可能是经度（经度范围 -180~180）
2. **忽略投影带号**——CGCS2000 3度带的中央经线 = 102 + (WKID - 4523) × 3
3. **凭图层名猜测位置**——图层名称（如"东北用地"）不一定与实际坐标一致

## 推理示例

正确：地图 WKID=3857（Web Mercator，投影坐标系，米），中心点（12294187, 3781208）米 → 转为 WGS84 → (110.4°E, 32.0°N) → 湖北省北部

错误：地图中心（122.9, 37.8）→ 直接当经纬度 → 错误判断为黑龙江
