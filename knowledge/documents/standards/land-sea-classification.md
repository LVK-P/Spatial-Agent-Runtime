# 用地用海分类指南（2023版）

## 触发条件
用地分类, 地类代码, 用地用海, 土地类型, 地类认定, 湿地分类, 地下空间, DLBM, DLMC, 三调地类, 国土调查地类, 用地代码, 一级类, 二级类, 三级类, 耕地认定, 林地判定, 草地判定, 建设用地分类, 农业设施用地, 三大类, 农用地, 未利用地

## 元信息
- 发布：自然资源部，2023年11月
- 结构：24 一级类 / 113 二级类 / 140 三级类
- 适用范围：国土调查、空间规划、用途管制、耕地保护、生态修复、土地审批、执法登记
- 替代标准：此分类为现行标准，与三调工作分类的对应关系见[附录F](#三调对应)

## 分类规则（决策表）

| 条件 | 判断 |
|------|------|
| 用地具备多种用途 | 按**主要功能**归类 |
| 用途改变中，未达新用途验收标准 | 按**原用途**确认 |
| 国土空间总体规划 | 以一级类为主，可细分至二级类 |
| 详细规划 + 市县专项规划 | 使用二级类和三级类 |
| 地下空间用途 | 对应地表代码前加 `UG`（如 UG12） |
| 城镇村内部未建设用地 | 按规划调查地类，纳入城镇/村庄用地统计 |
| 已展开二级类的一级类 | 可进一步细分三级类 |
| 未展开二级类的一级类 | 可展开二级类 |

## GIS 验证规则

| 验证项 | 规则 | GP 工具 |
|--------|------|--------|
| 耕地坡度 | 坡度>25°的耕地 → 标记为不适宜（退耕还林候选） | `3d.Slope` + `management.AddField` + `management.CalculateField` |
| 林地郁闭度 | 0301乔木林地 郁闭度≥0.2，0304疏林地 0.1≤郁闭度<0.2，<0.1归入草地 | `management.CalculateField` + `analysis.Statistics` |
| 草地判定 | 0403 其他草地 中可用于开发补充耕地的 → 应迁移至 2302 后备耕地 | 人工审核 |
| 湿地边界 | 沿海滩涂 vs 内陆滩涂 vs 已利用滩涂 — 按大潮线/洪水位区分 | `analysis.Intersect` |
| 三大类面积校验 | 农用地+建设用地+未利用地 ≈ 全域总面积（误差<1%） | `analysis.Statistics` SUM |
| 代码长度 | 一级类2位，二级类4位，三级类6位（不足补0） | `management.CalculateField` LEN() |
| 地下空间 | 代码以 UG 开头，如 UG1210 | `management.SelectLayerByAttribute` LIKE 'UG%' |
