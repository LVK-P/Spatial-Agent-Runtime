# 市级国土空间总体规划数据库规范（试行·2021）

## 触发条件
数据库规范, 图层字段, 属性表名, 字段类型, 字段长度, 值域, 约束条件, M/O/C, GDB Schema, YSDM, BSM, XZQDM, 要素代码, 标识码, 图层组织, 代码表, 投影, 坐标系, 高程基准

## 元信息
- 发布：自然资源部，2021年3月
- 坐标系：CGCS2000
- 投影：高斯-克吕格，国家标准分带
- 高程基准：1985国家高程基准
- 约束条件：M（必填）、O（可填）、C（条件必填）

## 要素分类编码规则

10位数字层次码：`XX` `XX` `XX` `XX` `X` `X`

| 层级 | 位数 | 含义 | 示例 |
|------|------|------|------|
| 大类码（专业码） | 2位 | 10=基础地理, 20=土地, 30=其他 | `10` |
| 小类码（业务码） | 2位 | 80=分析评价, 90=国土空间规划 | `80` |
| 一级类 | 2位 | 要素大类 | `00` |
| 二级类 | 2位 | 要素中类 | `04` |
| 三级类 | 1位 | 要素小类 | `0` |
| 四级类 | 1位 | 要素子类 | `1` |

> "其他"类代码直接设为 `9` 或 `99`。空位以 `0` 补齐。
